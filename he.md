# Read Me First — SEB Setup

- Full step‑by‑step instructions live here: `docs/SEB_SETUP.md`
- Summary:
  - No code changes required from you. Student‑facing endpoints are already protected by SEB checks.
  - Add one environment variable in Project Settings:
    - `SEB_ALLOWED_CONFIG_KEY_HASHES` = your SEB Config Key Hash(es), comma‑separated
  - Redeploy or restart your Preview. Test again using Safe Exam Browser.

If the editor shows “Old versions are read‑only”, click “Back to Latest” or “Restore” to switch to the editable, latest version.  
To download: click the three dots (…) in the top-right of the code preview → “Download ZIP”.
